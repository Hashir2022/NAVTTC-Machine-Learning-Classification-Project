# Classification Using Machine Learning and Deep Learning Models

## Project Overview
This project implements an end-to-end Machine Learning classification pipeline using the Adult Income Dataset. It analyzes demographic and employment-related data to predict whether an individual's annual income is above or below $50K.

## Key Features
- Exploratory Data Analysis (EDA)
- Data Cleaning and Preprocessing
- Feature Engineering and Encoding
- Implementation of Multiple Classification Models
- Model Performance Evaluation
- Interactive Machine Learning Dashboard
- Model Comparison and Visualization

## Machine Learning Models
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. Support Vector Machine (SVM)
5. Neural Network (MLP)

## Technologies & Libraries
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Plotly
- Jupyter Notebook / Google Colab
- IPyWidgets

## Dataset
Adult Income Dataset (Kaggle)

## Best Model Performance
Random Forest achieved the highest test accuracy of approximately **83.90%** among the evaluated models.

## Project Objectives
- Understand and analyze real-world datasets.
- Apply machine learning classification techniques.
- Compare different models using evaluation metrics.
- Develop an interactive dashboard for model analysis.
